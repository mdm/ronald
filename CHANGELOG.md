Changelog
=========

0.4.0
-----

* Fix service worker caching
* Validate assigned system ROMs at startup
* Improve performance of writing to screen
* Honor number of configured disk drives
* Improve debug event performance, especially if no breakpoints are set
* Support 6128 RAM banking
* Only render the visible portion of the memory view
* Show speed stats in debug controls overlay
* Additional small fixes

0.3.0
-----

* Overhaul of the floppy disk controller emulation
* Interactive system ROM configuration
* Upgrade patched egui version to 0.34.3
* Various small bug fixes and improvements
